⚖️ 5 key differences: Kruskal vs Prim

# PointKruskalPrim
1. ApproachEdge-based: picks the globally cheapest edge that does not form a cycle.Vertex-based: grows one tree by the cheapest edge leaving it.
2. Starting pointNo start node; begins with all edges sorted by weight.Starts from one chosen vertex (node 0 here).
3. Data structureSorted edge list + Union-Find (disjoint sets).Priority queue (min-heap) or adjacency matrix.
4. Time complexityO(E log E) = O(E log V).O(E log V) with a heap; O(V²) with a matrix.
5. Best for / behaviourSparse graphs; works on disconnected graphs (gives a forest); partial result is a forest.Dense graphs; needs a connected graph; partial result is always one connected tree.
